# Decap CMS Integration Guide

## Arsitektur Multi-Branch

```
Repository: alfath-rizqiy/web-tunakarya

Branch 'cms'  → Deploy: cms.domain.com/admin
                     ↓ (CRUD operations)
Branch 'patt' → Deploy: domain.com (Vercel)
                     ↓ (Auto rebuild)
              → Production Website
```

## Workflow

1. **Admin** akses `cms.domain.com/admin`
2. **Login** dengan GitHub OAuth
3. **Edit** konten melalui Decap CMS
4. **Publish** → Decap commit ke branch `patt`
5. **Vercel** auto-deploy branch `patt`
6. **Website** production terupdate

## Collections & Frontend Mapping

### 1. Struktur Organisasi

**Collection**: `struktur`  
**Folder**: `content/struktur/`  
**Frontend Component**: `Card.jsx` (`src/components/molecules/Card.jsx`)

```yaml
# Field Mapping
fields:
  - title     → props.name
  - role      → props.role
  - image     → props.image
  - order     → Urutan tampilan
  - active    → Filter tampilkan
```

**Frontend Usage**:
```jsx
// Strukture.jsx
import { fetchContent } from "../utils/contentLoader";

const members = await fetchContent("struktur");

// Render
<Card 
  image={member.image || fallbackImage}
  name={member.title}
  role={member.role}
/>
```

**Data Structure** (markdown frontmatter):
```yaml
---
title: "Alfath"
role: "Humas"
image: "/uploads/struktur/foto.jpg"
order: 1
active: true
---
```

## Setup Instructions

### 1. GitHub OAuth App Setup

1. Buka GitHub → Settings → Developer settings → OAuth Apps
2. Klik "New OAuth App"
3. Isi:
   - Application name: `Tunakarya CMS`
   - Homepage URL: `https://cms.domain.com`
   - Authorization callback URL: `https://cms.domain.com/auth`
4. Save Client ID dan Client Secret

### 2. Deploy CMS (Branch `cms`)

```bash
# Push folder cms ke branch 'cms'
git subtree split --prefix=cms -b cms-branch
git push origin cms-branch:cms
```

Di Vercel:
1. Import project dari GitHub
2. Pilih branch: `cms`
3. Root Directory: `/` (karena hanya ada cms files)
4. Framework Preset: `Other`
5. Build Command: (kosongkan)
6. Output Directory: `/`
7. Environment Variables:
   ```
   OAUTH_CLIENT_ID = <github-client-id>
   OAUTH_CLIENT_SECRET = <github-client-secret>
   ```

### 3. Deploy Frontend (Branch `patt`)

```bash
# Push web-tunakarya ke branch 'patt'
cd web-tunakarya
git push origin main:patt
```

Di Vercel:
1. Import project dari GitHub
2. Pilih branch: `patt`
3. Root Directory: `/`
4. Framework Preset: `Vite`
5. Build Command: `npm run build`
6. Output Directory: `dist`

### 4. Connect Decap CMS

Pastikan `config.yml` memiliki:
```yaml
backend:
  name: github
  repo: alfath-rizqiy/web-tunakarya
  branch: patt
  base_url: https://api.netlify.com
  auth_endpoint: auth
```

```javascript
import { fetchContent, fetchSettings } from "./utils/contentLoader";

// Fetch struktur data
const struktur = await fetchContent("struktur");

// Returns: [{ title, angkatan, profile, quotes, ... }]

// Fetch program data

// Returns: [{ title, image, description, ... }]

// Returns: { site_title, site_description, ... }
```

## Troubleshooting

### Media tidak muncul di frontend
- Pastikan `public/uploads/` ada di repository branch `patt`
- Cek path image di markdown: `/uploads/...` (bukan `/public/uploads/...`)

### CMS tidak bisa commit
- Verifikasi GitHub OAuth app callback URL
- Pastikan branch `patt` tidak protected (atau allow admin bypass)

### Data tidak update di frontend
- Clear browser cache
- Vercel rebuild mungkin masih berjalan (cek Vercel dashboard)

## Tips Production

1. **Use `active` field**: Semua collections punya field `active`. Gunakan untuk soft-delete tanpa menghapus data.

2. **Order management**: Gunakan field `order` untuk mengatur urutan tampilan tanpa rename file.

3. **Image optimization**: Upload gambar dengan ratio yang sesuai:
   - Struktur: 4:5 atau 1:1
   - Purna: 1:1 (bulat)
   - Program: 16:9

4. **Backup**: Content sudah di repository GitHub, jadi backup otomatis tersedia.
